# ⚡ Void Drop — Brawl Stars Rewards

![Void Drop Banner](https://cdn.jsdelivr.net/gh/lp77-br/void-drop@main/app/brawl-logo.png)

O **Void Drop** é o aplicativo oficial da **VoidHub** desenvolvido para centralização, verificação e resgate de recompensas, Pins, Sprays e Vouchers do **Brawl Stars**.

---

## 📱 Destaques do Aplicativo

- **Resgate Direto:** Links inteligentes e QR Codes para resgate instantâneo dentro do jogo.
- **Votação em Tempo Real:** Sistema de checagem da comunidade para indicar se uma recompensa ainda está ativa ou expirou.
- **Interface Otimizada:** Visual escuro (Dark Aesthetics), navegação fluida e carregamento leve.
- **Conteúdo Atualizado:** Sincronização automática de novidades em nuvem.
